# 快速上手

从零开始安装并使用。电脑端约十分钟；如果还要配置冰箱旁的触摸屏，再加约一小时。

[English version](QUICKSTART.md)

---

## 1. 实验室电脑

### 需要准备

- Windows 10 或 11
- [Python 3.9 或更高版本](https://www.python.org/downloads/) —— 安装时务必勾选
  **"Add Python to PATH"**
- [Git](https://git-scm.com/download/win)，或直接下载本仓库的 ZIP 压缩包

### 安装

```powershell
git clone <仓库地址> "D:\Lab Management"
cd "D:\Lab Management"
.\setup_windows.ps1 -WithExamples
```

如果 PowerShell 拒绝运行脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1 -WithExamples
```

脚本会创建虚拟环境、安装依赖、建立数据库、在桌面和开始菜单添加
**Lab Management** 快捷方式，并注册每小时自动备份。

`-WithExamples` 会填入一批**虚构的示例数据**，便于先熟悉界面。准备录入真实数据时，
**删除 `lab_management.db` 并去掉该参数重新运行**。

### 打开

双击 **Lab Management**。它会自动启动服务并打开独立窗口；无论点击多少次，
都只会有一个窗口。

## 2. 最初五分钟

顺序很重要：先描述存储结构，再往里放东西。

### 描述一台冰箱

菜单中的 **存储结构** → **编辑布局**。

1. **添加设备** —— 填写名称、类型和常用温度。
   如果是冷藏冷冻一体机，温度留空，改为在各个分区分别设置。
2. 在设备内添加**分区**（箱体、门体——按实际情况填写）。
3. 在分区内添加**层架**。将鼠标移到容器上点击 **+**；数量填大于 1 可一次添加多个。
4. 同样方式在层架内添加**架子**。

结构不要求统一。某一层可以放三个架子，下一层放五个；一台设备可以没有门体，
也可以有三个门体；某个分区可以有自己的温度。

### 说明一个架子里放了什么

**存储结构** → 点击某个架子。如果它是盒子组成的网格，在
**编辑布局** → 属性中设置其形状（此处 −80 °C 的架子为 4 列 × 4 行）。

点击某个**位置**并勾选存放的内容。位置只在有东西时才存在：
放入第一样东西即创建该位置，取走最后一样即释放。位置编号从左到右、
从上到下，**右侧为冰箱门一侧**。

### 添加试剂

**主页** → **添加新记录**。

粘贴供应商产品页面的网址，点击 **获取详情** —— 名称、货号、供应商、说明和
规格会自动填入空白字段。**已经填写的内容不会被覆盖。**

部分供应商会拒绝服务器访问，或页面由 JavaScript 生成。对于这些网站，
先设置一次 **Lab Capture** 书签（*导入/导出 → 浏览器抓取设置*），
在产品页面点击该书签，然后点击 **从浏览器获取**。

## 3. 撤销误操作

**导入/导出 → 历史记录与恢复。**

每条记录的每次更改都会保留。左侧列出所有已删除的记录，点击 **恢复**
即可还原到删除时的状态。右侧显示最近的更改以及每次改动了哪些字段。

## 4. 备份

安装时已自动配置，每小时备份到三个位置：

| 位置 | 可应对 |
|---|---|
| 项目内的 `backups\` | 一般误操作 |
| `..\LabManagementBackups\` | 整个项目文件夹被删除 |
| OneDrive（或 Google Drive） | 电脑损坏丢失 |

随时可手动运行一次：

```powershell
.\venv\Scripts\python.exe backup_db.py
```

恢复方法：把某个 `lab_management_*.db` 复制回去覆盖 `lab_management.db`，
然后重新打开应用。

> 冰箱旁的显示屏**不是备份**。它每几分钟就会被覆盖一次，
> 删除操作几乎会立刻同步过去。

## 5. 冰箱显示屏（可选）

在冰箱旁放一台带触摸屏的树莓派，用来查看东西放在哪里。它是**只读**的：
所有编辑仍在电脑上进行。

### 硬件

- 树莓派 4（2 GB 及以上）。树莓派 3B 可用；Zero 内存不足以运行浏览器。
- 7 英寸 1024×600 HDMI 触摸屏，**需配独立电源**
- 有线或无线网络连接

### 接线

```
        7 英寸屏幕                                树莓派
   +------------------+
   |  HDMI  ----------+----------------------->  HDMI0
   |  TOUCH ----------+----------------------->  任意 USB 口
   |  POWER <---------+--- 独立 5V 电源
   +------------------+                          树莓派 <-- 独立电源
```

**屏幕务必使用独立电源。** 仅接 TOUCH 口屏幕也会亮，但那样电流取自树莓派，
会引发看似其他部件故障的问题。

### 软件

在电脑上重新运行安装脚本并指定显示屏：

```powershell
.\setup_windows.ps1 -DisplayHost labfridge.local -DisplayUser labuser
```

脚本会打印需要在树莓派上执行的两条命令。屏幕显示模式的配置见
[deploy/README.md](../deploy/README.md) —— 这通常是唯一需要额外处理的环节：
这类面板往往不返回 EDID，解决办法是在 `cmdline.txt` 中加入 `video=` 参数。

## 6. 日常使用

| | |
|---|---|
| 添加或修改任何内容 | 在电脑上 |
| 在冰箱旁查找东西 | 用显示屏 |
| 更改同步到显示屏 | 5 分钟内自动完成 |
| 切换语言 | 菜单中的地球图标，或屏幕上的 **EN/中文** |

## 遇到问题时

**应用打不开。** 确认已安装 Python（`python --version`），然后重新运行
`setup_windows.ps1`——重复运行是安全的。

**显示屏数据过旧。** 屏幕角落会显示其地址和同步状态。如果显示 *未同步*，
在电脑上检查：

```powershell
.\venv\Scripts\python.exe sync_to_pi.py --status
```

**显示屏换了位置，IP 变了。** 直接从屏幕主界面读取新地址，
填入 `.sync_state.json`。

**误删了内容。** *导入/导出 → 历史记录与恢复。*
